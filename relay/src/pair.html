Limit Gauge ペアリング

Claude Code のリミットを表示する Android ウィジェット（非公式）の接続設定です。

スマホのカメラでこの QR コードを読み取ってください。

開いたページで「アプリで開く」をタップすると、接続設定がアプリに入ります。この QR コードには接続用のトークンが含まれるので、他人に見せないでください。

リミットゲージに接続設定を送ります。

アプリで開く 開かない場合はこちら

アプリ（APK）を先にインストールしておいてください。どちらのボタンでも開かない場合は、下の「手動で入力する」の値をアプリに入力してください。

このリンクにはトークンが含まれていません。

PC で npm run setup を実行したときに表示された URL をそのまま開いてください。
